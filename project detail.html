Shape Animation

Case Study | Adobe Audition

The project focuses on using basic skills in Adobe Audition to transform shapes, showcasing a little story for each shape. I had worked on this project by myself and I mainly wanted to focus on practicing my skills with editing and creating smooth transitions as it goes from one scene to the other. Each element was an exercise I learned in an Intro to Digital Arts class. Utilizing geometry, colors, animation, and creativity, is the stepping stones to motion graphics.
